# AK Preschool

Elternorientierte statische Portfoliodemo für Tagesablauf, Eingewöhnung und Informationsarchitektur einer Vorschule.

```bash
npm test
npm run lint
npm run build
python3 -m http.server 8000
```

Der lokale Gesprächsleitfaden verlangt keine personenbezogenen Daten, sendet nichts und erzeugt keine Anmeldung. GitHub Pages liefert die statischen Dateien aus.

Live: https://ak-hosting.github.io/ak-preschool/
